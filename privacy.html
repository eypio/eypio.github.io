Privacy Policy

Homelab Rclone is a personal, owner-operated connection for backing up and restoring the owner's data using Google Drive and rclone.

Google Drive access

The application requests Google Drive access for the account authorized by its owner. It can list, read, create, update, and delete Drive files as instructed by the owner for backup, retention, and recovery tasks. It is not made available to other users.

How data is used and stored

Google Drive data is used only to operate the owner's backup and restore workflow. The workflow is intended to encrypt backup contents locally with Restic before uploading them. Backup files are stored in the owner's Google Drive account according to their chosen retention policy.

OAuth credentials are stored on devices controlled by the owner, not in this website. The owner determines when backups are created, restored, or deleted.

Data sharing and advertising

The operator does not sell Google user data, use it for advertising, or provide it to third parties for their independent use. Google Drive stores the files as the chosen storage provider. This informational website runs on GitHub Pages, which may process ordinary website access information under GitHub's own policies.

Website activity

This website contains only static informational pages. It has no forms, analytics scripts, advertising trackers, or cookies set by this website's own code.

Access removal and deletion

The owner can revoke the app's Google account access at any time in Google Account settings. The owner can also delete backup files from Google Drive. Revoking access prevents further authorized API operations, but does not automatically delete existing backup files.

Google API Services User Data Policy

Use of information received from Google APIs is limited to the purposes described above and is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For questions about this personal application, contact the owner through the GitHub account publishing this website.
